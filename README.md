# Atlas Labs — HR Analytics Dashboard

## Overview
This Power BI report (`Atlas_Labs.pbix`) is an HR analytics dashboard built for **Atlas Labs**, providing a consolidated view of employee headcount, demographics, performance, and attrition. The report is organized into four interactive pages, each with its own focus area, and is driven by an underlying data model of employee, performance, and rating data.

### 4. Attrition
- KPI card(s) summarizing attrition figures
- Combo chart (line + clustered column) comparing attrition against another metric over time
- Funnel visual (likely tracking employee status stages, e.g., active → at risk → exited)
- Clustered column charts breaking attrition down by department, business travel, or overtime status

## Data Model
The report is built on a star-schema style model with the following key tables:

| Table | Purpose |
|---|---|
| `DimEmployee` | Core employee dimension — name, department, job role, gender, ethnicity, marital status, hire date, salary, age, overtime, business travel, attrition flag |
| `DimDate` | Date/calendar table for time intelligence |
| `FactPerformanceRating` | Performance review records, including review dates |
| `DimRatingLevel` | Lookup for rating scale values (e.g., manager/self ratings) |
| `DimSatisfiedLevel` | Lookup for satisfaction scale values |
| `Measures` (measures table) | Central DAX measures used across the report |

### Key Measures
- **% Attrition Rate**
- **Total Employee**
- **Active Employees / Inactive Employees**
- **Manager Rating / Self Rating**
- **Job Satisfaction / Environment Satisfaction / Relationship Satisfaction**
- **Work-Life Balance**
- **Next Review Date**

## Audience
HR management, business partners, and leadership who need a visual, filterable view of workforce composition, performance trends, and attrition drivers without pulling raw data manually.

## How to Use
1. Open `Atlas_Labs.pbix` in Power BI Desktop.
2. Use the page navigator at the top of each page to switch between Overview, Demographics, Performance Tracker, and Attrition.
3. Apply slicers/filters (department, job role, etc.) to narrow the analysis.
4. Use the decomposition tree visuals to drill into headcount and demographic breakdowns interactively.
